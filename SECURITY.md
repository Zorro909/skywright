# Security policy

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability
reporting for this repository so maintainers can investigate and coordinate a fix before public
discussion.

Repository dependency, source, and secret findings are governed by
[`docs/quality-gate.md`](docs/quality-gate.md#security-finding-policy). Security suppressions must be
narrow, issue-linked, and expiring; they are never accepted as permanent baseline exclusions.
